# Bar Notes

**Bar Notes** — одностраничное приложение для создания и ведения персональной барной карты. В приложении можно хранить рецепты коктейлей, добавлять фотографии готового напитка и отдельных этапов приготовления, редактировать данные и удалять рецепты.

Проект выполнен в рамках тестового задания на **Angular 21** с использованием **Angular Material**.

## Возможности

- просмотр коллекции в виде карточек или таблицы;
- поиск по названию и описанию коктейля;
- создание, просмотр, редактирование и удаление рецептов;
- динамическое добавление, удаление и изменение порядка этапов приготовления;
- загрузка главной фотографии и изображений отдельных этапов;
- автоматическое уменьшение и сжатие загружаемых изображений;
- подтверждение удаления через Material Dialog;
- защита от потери несохранённых изменений;
- адаптивный интерфейс для настольных и мобильных устройств;
- сохранение данных между перезагрузками страницы.

## Хранение данных

Приложение не требует backend-сервера. Рецепты сохраняются в `localStorage` под ключом:

```text
bar-notes.cocktails.v1
```

При первом запуске загружается стартовая коллекция из `cocktail.seed.ts`. После этого источником данных становится содержимое `localStorage`.

Чтобы сбросить локальные изменения и снова загрузить стартовые рецепты, выполните в консоли браузера:

```javascript
localStorage.removeItem('bar-notes.cocktails.v1');
location.reload();
```

### Обработка изображений

Перед сохранением пользовательские изображения обрабатываются в браузере:

- проверяется тип и размер файла;
- максимальный размер исходного файла — 10 МБ;
- максимальная сторона уменьшается до 960 пикселей;
- изображение преобразуется в JPEG;
- применяется сжатие перед записью в `localStorage`.

Это снижает расход доступного объёма локального хранилища. При его переполнении приложение показывает понятное сообщение и не изменяет текущее состояние коллекции.

## Архитектурные решения

- **Единая форма создания и редактирования.** Один компонент обслуживает оба сценария и уменьшает дублирование логики.
- **Signal-based store.** Состояние коллекции хранится в сервисе на Angular Signals, а компоненты получают реактивные данные без отдельной библиотеки управления состоянием.
- **Изолированный слой хранения.** Работа с `localStorage`, нормализация данных и обработка ошибок находятся в `CocktailStore`.
- **Ленивая загрузка страниц.** Главная страница, каталог, карточка рецепта и редактор загружаются отдельными chunks.
- **Защита пользовательских данных.** При попытке покинуть изменённую форму приложение запрашивает подтверждение.
- **Устойчивость к повреждённым данным.** Некорректное содержимое `localStorage` не ломает приложение — используется стартовая коллекция.

## Ограничения

- данные хранятся только в текущем браузере и не синхронизируются между устройствами;
- очистка данных сайта удалит созданные пользователем рецепты;
- объём изображений ограничен доступной квотой `localStorage`;
- серверная часть, регистрация и авторизация не используются.
